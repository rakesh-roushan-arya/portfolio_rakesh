# Rakesh Roushan Arya — Portfolio

A stunning personal portfolio website built with HTML, CSS & Vanilla JavaScript.

🌐 **Live:** https://rakesh-roushan-arya.github.io/portfolio_rakesh/

## ✨ Features
- Dark glassmorphism design with particle canvas background
- Animated typing effect & scroll reveal animations
- Interactive terminal with commands (`help`, `skills`, `projects`, `contact`)
- Fully responsive (mobile + desktop)
- Sections: Hero · About · Skills · Projects · Certifications · Achievements · Education · Contact

## 🚀 Tech Stack
HTML · CSS · Vanilla JavaScript
